# Livechat-Blogger [v.1.0]
Script Live Chat yg berguna untuk memudahkan visitor/pengunjung agar bisa saling berdiskusi langsung secara Realtime tanpa repot repot lagi meninggalkan jejak komentar yg sangat sulit sekali di notice bagi para pemilik Blogger, semua sudah saya buat selengkap mungkin dengan beberapa fitur diantaranya :

VERSI v1.0

- Chat Realtime permanen [Tanpa terhapus kecuali dihapus admin]
- Include fitur Admin [Bisa hapus pesan user & menyematkan pesan]
- Fitur Reply Chat ke sesama pengunjung
- Fitur Notification Badge (Counter) [Akan ada jumlah notifikasi setiap ada pesan masuk]
- Fitur Mention @ [Akan muncul logo mention ketika ada yg mention kamu]
- Fitur Slash / [Bisa berbagu list 50 postingan terakhir dengan mengetikkan / di kolom pesan]
- Notifikasi Online ketika admin sedang online
- Fitur PASSCODE [Admin bisa muncul dengan warna Buble chat khus dengan tulisan Admin dengan memasukkan Passcode tertentu]
